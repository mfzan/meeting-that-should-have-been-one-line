One line that replaces an entire pointless meeting: an hour, nine people, zero real decisions — except the donut rota. The meeting's only actual outcome was that Dave brings the donuts next Tuesday, which a group text could have settled in ten seconds.

## Run it

```sh
python3 main.py
```

It writes the single sentence to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).
